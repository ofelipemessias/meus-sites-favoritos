Página HTML comentada com GitHub, YouTube, Canva, Stack Overflow e EaDTEC. Cada site tem título, imagem local e link. As imagens também são clicáveis.

## Abrir a página

Baixe os arquivos e abra `8-FelipeMessias_Ag12_DS_I.html` no navegador. Mantenha as cinco imagens PNG na mesma pasta do HTML.

## Imagens da versão pública

Esta versão usa somente marcas dos sites, sem capturas de contas logadas. O HTML original foi preservado, com ajuste apenas dos caminhos das imagens. O pacote de entrega no AVA contém as capturas exigidas pelo enunciado.

- GitHub: imagem pública de https://github.com/fluidicon.png
- YouTube: ícone público do próprio site https://www.youtube.com/
- Canva, Stack Overflow e EaDTEC: recortes somente das marcas presentes nas imagens originais da atividade, sem dados de conta.

As marcas pertencem aos respectivos titulares e identificam os sites nesta atividade educacional.
